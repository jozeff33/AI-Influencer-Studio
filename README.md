# AI Influencer Studio — V0.2 (Development Prototype)

منصة عربية RTL لإدارة الشخصيات الافتراضية، نسخ الهوية البصرية، وصف مشاهد الصور، أرشفة المراجع البصرية وتوليد صور اختياري عبر OpenAI Images API.

## الترقية من V0.1

1. احتفظ بنسخة احتياطية من الملفات وقاعدة البيانات قبل التحديث.
2. على جهازك افتح مجلد Git الأصلي `C:\Users\MASTER\AI-Influencer-Studio` وأنشئ فرعاً جديداً باسم `feat/character-identity-v0.2`.
3. انسخ ملفات الحزمة الجديدة **فوق ملفات الكود فقط**؛ لا تحذف `.git`، ولا تنقل أو تستبدل ملف `.env` الخاص بجهازك.
4. إن أردت توليد صور مدفوعة، أضف `OPENAI_API_KEY=` إلى ملف `.env` المحلي بقيمة مفتاحك، وأضف `IMAGE_MODEL=gpt-image-1-mini`. لا ترفع المفاتيح إلى GitHub.
5. نفذ `docker compose up --build -d`، ثم افتح `http://localhost:3000`، وأدخل مساحة العمل والمفتاح المحليين كما في V0.1.

**مهم:** لا تنفذ `docker compose down -v` لأنه يحذف وحدات التخزين بما فيها البيانات المحلية. الإصدار يستخدم `create_all` لتهيئة الجداول الجديدة على سبيل التجربة فقط، ولا يتضمن مخطط migrations إنتاجياً.

## الجديد في V0.2

- حفظ إصدارات متعددة لوصف ملامح الشخصية وملابسها وأسلوب تصويرها، دون مسح الإصدارات السابقة.
- بناء وصف (prompt) للمشهد عبر آخر نسخة هوية، دون دفع أو اتصال بخدمة التوليد.
- رفع صور مرجعية PNG/JPEG/WEBP (حتى 8MB) إلى وحدة تخزين Docker مستقلة، مع التحقق من تنسيق الملف الحقيقي.
- عرض مكتبة الصور مرهونة بمفتاح التطوير ومساحة العمل.
- زر اختياري لتوليد صورة 1024×1024 عبر OpenAI Images API باستخدام `OPENAI_API_KEY` على الخادم فقط.
- مسودة المحتوى والشخصيات القديمة تظل محفوظة في قاعدة PostgreSQL إذا استُخدمت وحدات التخزين السابقة.

**الحدود:** الاعتماد على الوصف النصي وحده لا يضمن الحفاظ التام على ملامح الشخصية؛ الصور المرجعية لا تدخل بعد في طلب التوليد. طلب التوليد مباشر ومتزامن، بلا طابور مهام ولا مراقبة للتكلفة. لا توجد مصادقة إنتاجية أو نشر اجتماعي أو توليد فيديو. يجب استخدام المشروع محلياً للتطوير فقط.

## اختبار الإصدار

```bash
cd backend
python -m pip install -r requirements.txt
python -m pytest -q
```

## الواجهات الجديدة

| Endpoint | الوظيفة |
| --- | --- |
| `GET/POST /characters/{id}/identity` | قراءة/إضافة إصدارات الهوية |
| `POST /characters/{id}/prompt-preview` | معاينة وصف المشهد |
| `POST /characters/{id}/references` | أرشفة صورة مرجعية |
| `GET /characters/{id}/assets` | مكتبة صور الشخصية |
| `GET /assets/{asset_id}` | إرجاع صورة بعد التحقق من صلاحية مساحة العمل |
| `POST /characters/{id}/images` | توليد صورة فعلية عند إعداد مفتاح خدمة OpenAI |

## أمان التطوير

مفتاح `STUDIO_DEV_API_KEY` مشترك ومساحة العمل يحددها الطلب؛ هذا ليس عزل حسابات آمناً للإنتاج. لا تعرّض الخدمات للإنترنت ولا ترفع `.env` أو أي صور خاصة إلى مستودع عام. لتطوير إنتاجي حقيقي نحتاج OIDC، RBAC، RLS، migrations، سياسات احتفاظ، حماية موارد وخط مهام غير متزامن.
