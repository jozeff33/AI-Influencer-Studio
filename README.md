# AI Influencer Studio — V0.1 (Prototype)

نموذج أولي عملي للوحة تحكم عربية RTL مع FastAPI وPostgreSQL وإدارة شخصيات ومشاريع محتوى متعددة.

## التشغيل
1. انسخ `.env.example` إلى `.env` واستبدل `STUDIO_DEV_API_KEY` بمفتاح عشوائي قوي.
2. شغّل `docker compose up --build` (يتطلب Docker وDocker Compose).
3. افتح http://localhost:3000 وأدخل نفس المفتاح ومساحة عمل `demo`.
4. وثائق API على http://localhost:8000/docs.

## الاختبارات
```bash
cd backend
python -m pip install -r requirements.txt
python -m pytest -q
```

## حدود الإصدار
- مفتاح تطوير واحد مع X-Organization-ID للاختبار فقط، **ليس نظام مصادقة إنتاجياً**. لا تنشره على الإنترنت.
- لا يوجد بعد توليد صور أو فيديو أو صوت أو ربط حسابات اجتماعية.
- لا توجد بعد طوابير مهام أو صلاحيات متعددة أو سجل تدقيق أو ترحيلات Alembic.
- تهيئة قاعدة البيانات تتم تلقائياً لأغراض النموذج الأولي فقط.
- في الإصدار الإنتاجي: OIDC/JWT، عضويات المؤسسات المستخرجة من التوكن وليس الهيدر، RLS، تخزين وسائط S3، ترحيلات، فحص مدخلات، حدود معدل، أسرار آمنة ومراجعة النشر.
- إعداد Docker Compose مخصص للتطوير المحلي، وليس للنشر العام.
