# AI Influencer Studio — V0.4 (Local Development Prototype)

استوديو لإدارة عدة شخصيات افتراضية، هويات بصرية بإصدارات غير قابلة للاستبدال، مشروعات، توليد صور وفيديو اختياري، وقصص متعددة الحلقات تُكتب وتُجهّز تلقائياً. الواجهة عربية كاملة وRTL.

## وحدات النظام

- V0.1: الشخصيات والمسودات PostgreSQL + FastAPI + Next.js.
- V0.2: هويات مرئية مصنفة بإصدارات وصور مرجعية ومكتبة محلية.
- V0.3: وظائف الصور والفيديو ومراجعة ثبات الملامح والمزودان OpenAI/Runway (اختياريان).
- **V0.4 Story Autopilot:** عالم الشخصية، الوقائع الثابتة، الحلقات المتتابعة، الذاكرة والسياق، السيناريو، مشاهد ريلز 9:16، محاضر التحضير، عامل جدول منفصل، حد يومي للطلبات المدفوعة، وتجميع الفيديو بـ FFmpeg (عند وجود مقاطع مكتملة).

## التشغيل المحلي

1. انسخ `.env.example` إلى `.env` ثم استبدل `STUDIO_DEV_API_KEY` بمفتاح تطوير عشوائي قوي خاص بك.
2. `docker compose up --build -d`
3. افتح `http://localhost:3000` وأدخل مساحة العمل `demo` ومفتاح التطوير الموجود في `.env`.
4. وثائق API على `http://localhost:8000/docs`.
5. إذا أردت تشغيل الأتمتة المستمرة: **بعد** إعداد السيرة وتفعيل جدولة الحلقة من داخلها، نفذ `docker compose --profile autopilot up -d --build`.

## الأمان والتكاليف

**لا تنشر هذا النموذج مباشرة على الإنترنت.** مفتاح التطوير المشترك و`X-Organization-ID` ليسا بديلاً لتسجيل دخول المؤسسات وعزل البيانات الفعلي. لا ترفع `.env` أو وسائطك إلى GitHub.

طلبات خدمات النصوص والصور والفيديو المدفوعة **مغلقة افتراضياً**، وتحتاج إلى تفعيل متعدد المستويات مع حد لعدد الطلبات يومياً. العدد ليس حدّاً للتكلفة المالية، لذا راقب استخدام الحساب لدى المزود. لا يُنشر المحتوى تلقائياً إلى شبكات التواصل.

لمزيد من خطوات النسخ الاحتياطي والترقية: [UPGRADE_V0.4_AR.md](UPGRADE_V0.4_AR.md).

## اختبار الخلفية

```bash
cd backend
python -m pip install -r requirements.txt
python -m pytest -q
```

الملفات والوظائف في هذا الإصدار تعمل كمخطط أولي؛ بناء واجهة Next.js وتجربة خدمات التوليد المدفوعة يحتاجان فحصاً محلياً على جهاز التشغيل.
